# HappyGhastHarnessMod

Fabric-Mod fuer Minecraft **26.3**: Soul Speed auf Happy-Ghast-Harnesses.

- Soul Speed kann **nur per Amboss** (Verzauberungsbuch + Harness) auf ein Harness gelegt werden, nicht im Verzauberungstisch.
- Fluggeschwindigkeit des Happy Ghasts mit Spieler als Reiter: Stufe 1 = 1,5x, Stufe 2 = 2x, Stufe 3 = 2,5x.
- Serverseitig; der Client braucht die Mod nicht zwingend.

## Bauen
Siehe `gradle.properties` (Versionen fuer 26.3 pruefen auf https://fabricmc.net/develop/), dann `gradle build`.
Die Jar liegt in `build/libs/`. Alternativ baut der GitHub-Actions-Workflow die Jar als Artifact.
